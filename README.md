# منصة منشئ المستندات التعليمية AI — 1448-1449هـ

نسخة قابلة للتشغيل محليًا. المسار: المرحلة ← الصف ← المادة ← الفصل الأول/الثاني ← الوحدة ← عدة دروس ← نوع المستند ← مواصفات الفقرات ← معاينة ← اعتماد ← PDF/Word.

التشغيل:
python -m venv .venv
pip install -r requirements.txt
python app.py
ثم افتح http://127.0.0.1:5000

مهم: بيانات الوحدات والدروس في data/curriculum.json حقول ربط تجريبية وليست أسماء رسمية؛ لا ينبغي اعتبارها منهج 1448. يجب استيراد بيانات الكتب الرسمية المعتمدة قبل النشر العام. نقطة /api/generate جاهزة لربط مزود AI على الخادم، مع إبقاء المفتاح سريًا.
